# messenger-inbox

Чат на React: вводишь ключи своего инстанса [GREEN-API](https://green-api.com/),
номер собеседника — и переписываешься текстом через WhatsApp. Окно чата
срисовано с WhatsApp Web. Это тестовое задание, поэтому функций ровно столько,
сколько нужно для сценария «отправил — получил ответ».

## Запуск

Нужен Node 20+ и pnpm.

```bash
pnpm install
pnpm dev
```

Откроется на http://127.0.0.1:5173/.

Без инстанса GREEN-API приложение показывать нечего, так что сначала:

1. завести инстанс в личном кабинете green-api.com;
2. привязать WhatsApp по QR-коду — статус инстанса должен стать `authorized`,
   иначе экран входа не пустит дальше;
3. в настройках инстанса включить входящие уведомления (`incomingWebhook`).
   Без этого ответы собеседника не придут: они складываются в очередь на стороне
   GREEN-API, а приложение только читает её;
4. скопировать `idInstance` и `apiTokenInstance` — их и спрашивает форма входа.

Адрес API собирается сам: `https://{первые 4 цифры idInstance}.api.green-api.com`.
Если у вашего инстанса он другой — положите свой в `VITE_API_BASE_URL`
(шаблон лежит в `.env.example`).

Остальные скрипты: `pnpm build` (проверка типов плюс сборка в `dist`),
`pnpm preview`, `pnpm lint`, `pnpm test`.

## Стек

React 19 и TypeScript на Vite, состояние — Redux Toolkit, запросы — RTK Query,
стили — CSS Modules, тесты — Vitest. Роутера и UI-кита нет: экранов три,
компонентов десяток, тянуть ради них библиотеки смысла не было.

## Что где

`src/api` — всё общение с GREEN-API. Учётные данные подставляются в URL
в одном месте, в `messengerApi.ts`, так что смена эндпоинтов — правка одного
файла. Там же `notifications.ts`, который переводит вебхуки в наши сообщения.

`src/features/chat` — сам чат. Самое интересное здесь — `usePollNotifications.ts`:
бесконечный цикл `ReceiveNotification`, после каждого уведомления обязательный
`DeleteNotification` (иначе то же самое придёт снова), пауза с удвоением при
обрывах сети и остановка, пока вкладка скрыта. Дедупликация по `idMessage`
живёт в `chatSlice.ts` — она же спасает от задвоения, когда API присылает
эхо нашего собственного сообщения.

`src/app` — стор и сохранение сессии с перепиской в `localStorage`.

## Деплой

Это статика, бэкенда нет. На Vercel хватает импорта репозитория: пресет Vite
определяется сам, команда сборки `pnpm build`, каталог `dist`, переменные
окружения не нужны.

Ключи в сборку не попадают — их вводит пользователь, и дальше его браузера они
не уходят. Так что публичная ссылка безопасна: без своего инстанса с неё
ничего не отправишь.

## Чего здесь нет

Только текст — ни медиа, ни файлов, ни групп. Один чат за раз, списка диалогов
нет. История не подтягивается из WhatsApp: лента копится с момента, как вы
открыли приложение, и лежит в `localStorage`. Там же лежит токен инстанса —
для тестового задания нормально, но в продакшене ключи в браузер отдавать
нельзя, нужен свой прокси.

## Грабли

Две штуки, на которых можно потерять вечер:

- Хост API — `green-api.com`, а не `greenapi.com`. Второй домен существует,
  но поддомены инстансов на нём не резолвятся, и браузер отдаёт
  `ERR_NAME_NOT_RESOLVED`.
- Vite по умолчанию слушает IPv6-loopback. Если `localhost` на машине
  резолвится в IPv4, браузер получает `ERR_CONNECTION_REFUSED` на живом
  сервере. Поэтому в `vite.config.ts` явно прописан `host: '127.0.0.1'`.
